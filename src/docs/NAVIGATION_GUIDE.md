# Admin Navigation Guide

## Getting Started

Welcome to the a2z Utility Hub Admin Panel. This guide will help you navigate the system efficiently.

## Layout Overview

The admin panel consists of three main areas:
1.  **Sidebar**: Primary navigation menu on the left.
2.  **Top Bar**: Quick actions, profile, and mobile menu toggle.
3.  **Main Content Area**: Where you perform your tasks.

## Sidebar Navigation

The sidebar allows access to all modules. 
*   **Groups**: Related items are grouped together (e.g., Content Management). Click a group to expand/collapse it.
*   **Collapsing**: On desktop, use the button at the bottom of the sidebar to collapse it into icon-only mode for more space.
*   **Mobile**: On mobile devices, tap the menu icon in the top left to open the sidebar drawer.

## Permissions

What you see in the sidebar depends on your **Role** and **Permissions**.
*   If you don't see a menu item, you likely don't have the required permission.
*   Contact a Super Admin to request access.

## Keyboard Shortcuts

*   **Tab**: Navigate through interactive elements.
*   **Cmd/Ctrl + F**: Use browser search to find text on the current page.

## Common Actions

### Logging Out
Click the "Sign Out" button in the top right corner of the Top Bar.

### Managing Profile
Your current role is displayed in the Top Bar. Profile settings can be accessed via "Settings" > "General".

## Troubleshooting

**I can't access a page:**
*   Ensure you are logged in.
*   Check if you have the correct permissions.
*   Refresh the page.

**The sidebar is stuck:**
*   Try clearing your browser cache or resizing the window.
