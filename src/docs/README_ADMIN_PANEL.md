# a2z Utility Hub - Admin Panel

## Introduction
This is the administrative interface for the a2z Utility Hub. It provides authorized personnel with tools to manage content, users, settings, and view analytics.

## Quick Start
1. **Login**: Go to `/admin/login`.
2. **Dashboard**: Upon login, you will see the main dashboard.
3. **Navigation**: Use the sidebar to access different modules.

## Key Features
- **Secure**: RBAC ensures users only see what they are allowed to.
- **Audit Trails**: All critical actions are logged.
- **Responsive**: Works on Desktop and Tablet.
